Research Brief 2 2024 JEL: C82, Q11, E37 · 2015 – 2024 · Python (pandas, matplotlib, FRED API)

Automating Commodity Price Time-Series Analysis with Python and FRED API

Angie Manuela Gutierrez-Oviedo · Fundación Universitaria del Área Andina · 2024
FRED API pandas matplotlib Automation Time Series Reproducibility
Abstract
Resumen
This brief demonstrates how the FRED API and Python can automate the retrieval and time-series analysis of agricultural commodity prices, replacing the manual Excel workflows used in 2020–2023. The brief develops reusable functions for data retrieval, cleaning, transformation, and visualization that serve as building blocks for the 2024 capstone. The automated pipeline reduces workflow time from 2–3 hours (manual) to under 5 minutes, with 12 commodity price series retrieved and processed in 187 lines of code. Commodity prices peaked at index 196 (Q3 2022) during the supply chain crisis before normalizing to index 118 by Q2 2024.
Keywords: FRED API, Python automation, time series, reproducibility, commodity prices, pandas, fredapi
1.
Research Question
Pregunta de Investigación

How can the FRED API and Python automate the retrieval and time-series analysis of agricultural commodity prices, replacing manual Excel workflows?

H₀ (Null Hypothesis): Automated API-based data retrieval provides no significant improvement in workflow efficiency or reproducibility compared to manual download-and-process workflows.

H₁ (Alternative Hypothesis): Automated API-based retrieval significantly reduces workflow time (>80% reduction), eliminates manual errors, and enables full reproducibility through documented code.

Every analysis in the 2020–2023 portfolio began with manual data download, copy-paste into spreadsheets, and format-specific cleaning. This brief asks: can the entire data pipeline — from source to visualization — be automated in code, making the analysis instantly reproducible and updatable?

2.
Data & Sources
Datos y Fuentes

Data is retrieved entirely through the FRED API using Python's fredapi library, accessing 12 commodity price series relevant to Colombian agricultural markets.

Each series is retrieved with a single API call, merged on date index, and converted to a normalized index (base 100 = January 2020).

3.
Methodology
Metodología

The brief develops a modular Python pipeline with reusable functions, following software engineering best practices.

Step 1 — API connection and retrieval functions. A wrapper function handles FRED API authentication using fredapi.Fred(api_key), series retrieval with error handling (try/except blocks for missing series), and automatic date filtering. The function get_fred_series(series_ids, start_date, end_date) accepts a list of series IDs and returns a merged DataFrame.

Step 2 — Data cleaning pipeline. Automated functions for missing value interpolation (df.interpolate(method='time')), frequency conversion (daily to monthly using df.resample('M').mean()), outlier flagging (Z-score > 3), and unit standardization. Each step is documented with docstrings and inline comments.

Step 3 — Index normalization. All price series are converted to index form (base 100 = January 2020) using df / df.loc['2020-01'] * 100, enabling cross-commodity comparison regardless of original units.

Step 4 — Visualization templates. Reusable matplotlib functions for common chart types: dual-axis time series, scatter with regression line, rolling statistics, and multi-panel comparison. Template function: plot_commodity_index(df, commodities, title, save_path).

4.
Key Finding
Hallazgo Principal

The methodological brief demonstrates that the entire FRED-to-visualization pipeline can be automated in 187 lines of Python code, with dramatic efficiency gains.

Key Finding
Hallazgo Principal
Workflow time: 2–3 hours → under 5 minutes — a >95% reduction in time from data retrieval to initial visualization. The pipeline is fully reproducible: running the same notebook at any future date automatically retrieves updated data.

12 commodity series × 120 months = 1,440 observations retrieved, cleaned, and indexed in a single code execution. Manual workflow would require 12 separate downloads, 12 copy-paste operations, and 12 format conversions.

Commodity price peak: index 196 (Q3 2022) — Brent oil and wheat reached their maximum during the post-pandemic supply chain crisis. By Q2 2024, the commodity index normalized to 118, a 40% decline from peak.

H₁ confirmed: Automation provides >95% time reduction and complete reproducibility versus manual workflow.

Automation is not just about speed — it is about reproducibility and error reduction. The manual workflows of 2020–2023 were vulnerable to copy-paste errors, version confusion, and undocumented transformations. The code-based approach makes every step explicit and auditable.

5.
What I Learned
Lo que Aprendí

API-based data retrieval fundamentally changed my analytical workflow. Instead of downloading files, the data comes programmatically — and this means the analysis is always current, always reproducible, and always documented.

Writing reusable functions with docstrings introduced software engineering principles into research: DRY (Don't Repeat Yourself), separation of concerns, and code documentation. These practices scale directly to the 2025 working paper's codebase.

Building matplotlib visualization templates taught me that good visualization starts with good defaults — pre-configured color palettes, consistent axis formatting, and readable annotations that can be applied to any dataset with minimal customization.

6.
Limitation
Limitación
Scope Limitation
Limitación del Alcance
The brief focuses on FRED data only. Other key sources (SIPSA-DANE, UN Comtrade, FAO) do not have equivalent Python APIs and still require manual download or web scraping. Building API wrappers or scrapers for these sources would complete the automation pipeline but is outside the scope of this brief. The FRED limitation means Colombian domestic prices must still be processed manually.
7.
Policy Implication
Implicaciones de Política

The methodological advancement demonstrated in this brief has direct implications for agricultural policy research capacity. The ability to rapidly retrieve, process, and visualize commodity price data enables more responsive policy analysis — turning a monthly reporting cycle into an on-demand capability.

For Colombian agricultural research institutions, the pipeline provides a template for building reproducible analysis infrastructure. The FRED API access is free with registration, and the Python code is open-source, lowering barriers to adoption. Investment in API-based automation infrastructure could significantly increase the analytical throughput of agricultural economics research units.
