Colombian Agricultural Market Intelligence Dashboard 2019–2023

Angie Manuela Gutierrez-Oviedo · Fundación Universitaria del Área Andina · 2023
FRED FAOSTAT UN Comtrade SIPSA-DANE Power Query DAX Measures Star Schema
Abstract
Resumen
This capstone builds an interactive Power BI dashboard that integrates currency risk, biotechnology trends, and trade geography into a single market intelligence tool for Colombian agricultural markets. Using Power Query for data transformation and Power BI's star-schema data model, the dashboard connects FRED macroeconomic data, FAO production statistics, UN Comtrade trade flows, and SIPSA-DANE domestic prices. Key metrics surfaced: import cost index peak of 152, volatility peak of 22.6%, and US export share of 33.5%. The dashboard enables non-technical stakeholders to explore these relationships through interactive slicers, maps, and drill-through pages.
Keywords: Power BI dashboard, agricultural intelligence, data integration, Power Query, DAX, star schema, executive reporting
1.
Research Question
Pregunta de Investigación

Can an interactive Power BI dashboard integrate currency risk, biotechnology trends, and trade geography into a single market intelligence tool accessible to non-technical stakeholders?

H₀ (Null Hypothesis): Integrating multiple data sources in Power BI produces a fragmented user experience with no analytical coherence across themes.

H₁ (Alternative Hypothesis): A well-designed star-schema data model enables unified cross-source analysis, allowing stakeholders to explore macro-micro relationships through consistent slicer interactions.

The 2020–2022 portfolio produced valuable analyses, but each existed as a separate file — disconnected spreadsheets and SQL exports requiring manual navigation. The 2023 challenge is integration: can multiple data sources and analytical perspectives be unified in a single interactive tool?

3.
Methodology
Metodología

The capstone applies Power BI's full stack: Power Query for ETL, data modeling for relationships, DAX for calculated measures, and visualization for interactive storytelling.

Step 1 — Power Query ETL pipeline. Each data source is imported, cleaned, and transformed: date formats standardized to YYYYMM, frequencies harmonized to monthly, missing values handled with linear interpolation, and lookup tables created for consistent coding across sources.

Step 2 — Star-schema data model. A central fact table (price observations with 2,400+ records) connects to dimension tables (products, markets, dates, countries) through primary-foreign key relationships, enabling cross-source analysis without manual merging.

Step 3 — DAX calculated measures. Custom measures compute: Volatility_30d = STDEV.P(Price) / AVERAGE(Price) × 100, price indices (base-100), growth rates (YoY%), and trade concentration (HHI). These measures are reusable across all dashboard pages.

Step 4 — Interactive dashboard pages. Five pages — Price Monitor, Currency Risk, Trade Geography, Biotech Trends, and Executive Summary — each with synchronized slicers for time period, product, and country.

4.
Key Finding
Hallazgo Principal

The dashboard itself is the finding: a functional proof-of-concept that agricultural market intelligence can be delivered through integrated interactive visualization.

Key Finding
Hallazgo Principal
Import cost index reached 152 (base 100 = January 2019) during the October 2022 crisis peak, with 30-day volatility reaching 22.6% — both metrics visible in real-time on the Currency Risk page.

US export share remains dominant at 33.5% but the dashboard reveals gradual diversification toward Asian markets. The Trade Geography page's drill-through functionality shows that coffee drives the US relationship while flowers are the primary EU export.

Cross-source insights emerge from slicer interaction: filtering to "corn" reveals simultaneous high import costs (currency page), low domestic yields (biotech page), and concentrated import sourcing from Argentina (trade page) — a coherent narrative across previously disconnected analyses.

The interactive format enables stakeholder-driven exploration — a non-technical user can filter by product, period, and country to test hypotheses without modifying underlying data or formulas.

5.
What I Learned
Lo que Aprendí

Building a star-schema data model in Power BI taught me relational data architecture — the same principles that underpin SQL databases. Understanding how fact tables and dimension tables connect through keys fundamentally changed how I think about organizing analytical data.

Writing DAX measures for rolling volatility and price indices introduced a formula language conceptually closer to programming than to spreadsheet formulas. The experience of defining reusable calculated measures bridges toward Python function writing in 2024.

Designing interactive dashboards for non-technical audiences taught me to separate analytical complexity (hidden in the data model and DAX) from user experience (clean visuals with intuitive filters). This separation of concerns is a design principle that carries through all subsequent work.

6.
Limitation
Limitación
Tool Limitation
Limitación de Herramienta
Power BI's statistical capabilities are limited compared to dedicated statistical software. The dashboard computes descriptive statistics and visualizes trends but cannot perform regression analysis, significance testing, or time-series modeling natively. These limitations motivate the transition to Python in 2024.
7.
Policy Implication
Implicaciones de Política

The dashboard demonstrates that integrated market intelligence is feasible with existing public data sources. For Colombia's Ministry of Agriculture, a production-quality version of this dashboard could serve as a real-time monitoring tool, alerting policymakers when import costs or volatility exceed threshold levels.

The cross-source drill-through capability enables scenario analysis: "What happens to corn import costs if the peso depreciates 10% while Argentine harvests decline?" — a question previously requiring manual coordination across multiple analyses, now answerable through slicer interaction.

8.
Deliverable
Entregable
