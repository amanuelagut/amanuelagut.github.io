USD/COP Exchange Rate Risk and Agricultural Import Costs: A Power BI Visual Analysis

Angie Manuela Gutierrez-Oviedo · Fundación Universitaria del Área Andina · 2023
FRED Banco de la República Power BI Exchange Rate Import Costs Pass-Through
Abstract
Resumen
This brief extends the 2020 USD/COP-to-agricultural-import-cost analysis using Power BI's interactive visualization capabilities to communicate findings to non-technical audiences. The analysis covers 48 monthly observations from January 2020 to December 2023, during which the peso depreciated 40.4% from COP 3,436 to a peak of COP 4,824 (November 2022). The import cost index rose from 100 to 152 over the same period. The visual correlation (r = 0.847, p < 0.001) demonstrates that Power BI can effectively translate statistical relationships into actionable executive insights.
Keywords: exchange rate risk, agricultural imports, Colombia, Power BI, visual analytics, pass-through elasticity, currency volatility
1.
Research Question
Pregunta de Investigación

Can Power BI effectively communicate the relationship between USD/COP volatility and agricultural import cost dynamics to a non-technical executive audience?

H₀ (Null Hypothesis): There is no significant visual correlation between USD/COP exchange rate movements and agricultural import cost index changes over the 2020–2023 period (r < 0.30).

H₁ (Alternative Hypothesis): A strong positive visual correlation exists between USD/COP depreciation and agricultural import cost increases, demonstrable through interactive Power BI visualizations (r ≥ 0.70).

The 2020 analysis established this relationship statistically using Excel regression. This brief asks a different question: can the same insight be communicated visually to decision-makers who do not interpret regression coefficients? Colombia's agricultural sector imports approximately USD 12 billion in inputs annually, making exchange rate risk communication critical for policy and business planning.

The extended period (48 months) captures three distinct regimes: COVID shock (March–June 2020), gradual depreciation (2021), crisis peak (October–November 2022), and partial recovery (2023). This variation enhances visual storytelling opportunities.

3.
Methodology
Metodología

The brief focuses on visualization design for executive communication rather than statistical computation.

Step 1 — Dual-axis time series. USD/COP and import cost index plotted on synchronized dual axes using Power BI's line chart visual. Conditional formatting highlights periods where 30-day volatility exceeds 15% (crisis periods) in red shading.

Step 2 — Scatter plot with trend line. Power BI's scatter chart with built-in linear regression trend line shows the exchange rate-import cost relationship. The equation ImportCost = 0.82 × (ΔUSDCOP) + ε is displayed dynamically, updating with slicer selections.

Step 3 — KPI cards with annotations. Executive summary page displays key metrics: correlation coefficient (r = 0.847), pass-through elasticity (0.82), peak depreciation date (Nov 2022), and maximum import cost index (152). Plain-language tooltips explain each metric.

4.
Key Finding
Hallazgo Principal

The visual analysis demonstrates that Power BI can translate complex exchange rate dynamics into immediately intuitive executive dashboards.

Key Finding
Hallazgo Principal
USD/COP depreciated 40.4% from COP 3,436 (Jan 2020) to COP 4,824 (Nov 2022), with 30-day volatility peaking at 22.6% during the Ukraine crisis period. The agricultural import cost index rose from 100 to 152 over the same period.

Visual correlation r = 0.847 (p < 0.001) is immediately apparent in the dual-axis chart where the two lines move in near-lockstep. The pass-through elasticity of 0.82 means that a 10% peso depreciation translates to an 8.2% increase in import costs.

Two crisis periods are visually distinct: COVID peak (March 2020) and Ukraine crisis (October 2022). The conditional formatting in red makes these periods stand out without requiring statistical interpretation.

Stakeholder feedback indicated that the visual format was "more actionable than the 2020 regression tables" — executives could immediately identify high-risk periods and understand pass-through magnitude without statistical training.

5.
What I Learned
Lo que Aprendí

Visualization as communication — not just as analysis output — was the central lesson. The choice between a line chart and a scatter plot is fundamentally a communication decision about which relationship to emphasize for the target audience.

Power BI's conditional formatting and dynamic titles enable data-driven storytelling where the visual itself adapts to the data. The red highlighting on high-volatility periods draws attention automatically, reducing the need for manual annotation.

The exercise of revisiting a 2020 analysis with a 2023 tool demonstrated that the same question can produce deeper insight when approached with more sophisticated visualization instruments. The statistical relationship was already known; the visualization made it actionable.

6.
Limitation
Limitación
Scope Limitation
Alcance de la Limitación
The brief prioritizes visual communication over analytical depth. The underlying statistical relationship is assumed from the 2020 and 2022 analyses rather than re-estimated with formal regression. A more rigorous approach would embed Power BI's R or Python visual integration to compute and display regression results with confidence intervals within the dashboard itself.
7.
Policy Implication
Implicaciones de Política

The 0.82 pass-through elasticity implies that exchange rate volatility management is more cost-effective than direct import price controls for stabilizing agricultural input costs. Each 10% reduction in peso volatility would prevent approximately 8.2% import cost spikes.

For Colombia's Ministry of Agriculture and Banco de la República, the visual analysis supports communication of currency risk to agricultural stakeholders. The dashboard format enables real-time monitoring: updating the FRED data feed automatically refreshes all visualizations, providing an early warning system for import cost pressures when the peso depreciates beyond threshold levels.

8.
Deliverable
Entregable
